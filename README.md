# AI-Based Face Recognition Attendance System

This project presents an automated attendance system using face recognition and blink detection for accurate and secure attendance marking. Initially, student images are captured and stored in a dataset. During execution, the system uses a webcam to capture live video, detects faces, and compares them with the stored dataset to identify students.

To ensure the presence of a real person, blink detection is used as a liveness check. Once a student is recognized and verified, attendance is automatically recorded with date and time in an Excel file.

This system reduces manual effort, improves accuracy, and prevents proxy attendance in classrooms and similar environments.
